# Practical Task #02 – Dart Control Flow & Data Structures

This repository contains my solution for **Practical Task #02** as part of the **Flutter Development Track at NextGen Institute**.

## Topics Covered

* Lists
* Maps
* Functions
* Loops
* `if / else` conditions
* `switch-case`
* User input
* Calculations
* Data manipulation

## Tasks

### 1. Shopping Cart Total

* Accepts the prices of 5 products from the user.
* Stores the prices in a list.
* Calculates and displays:

  * Total price
  * Average price

### 2. Find the Largest Number

* Accepts 5 integers from the user.
* Stores them in a list.
* Uses a `findLargest` function to find and return the largest number.

### 3. Student Information

* Stores student information in a Map:

  * Name
  * Age
  * Grade
  * Passed status
* Displays the student's information.
* Updates the student's grade and displays the updated information.

### 4. Count Numbers

* Uses a `countNumbers` function to count:

  * Positive numbers
  * Negative numbers
  * Zeros
* Returns the results as a `Map<String, int>`.

### 5. Simple ATM Simulation

* Starts with an initial balance of 5000.
* Allows the user to:

  * Check balance
  * Deposit money
  * Withdraw money
  * Exit
* Uses a `while` loop and `switch-case` to handle transactions.
